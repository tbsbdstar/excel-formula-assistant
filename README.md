# Excel 智能函数助手（MVP）

按《Excel 智能函数助手.md》PRD V1.0 实现的纯前端工具。用户拖入表格、用一句中文描述需求，就能得到 Excel 2016 / WPS 兼容的公式和计算结果，并可下载 .xlsx 文件（可选择保存“结果值”或“公式”）。

> **V2.0 工作流（多文件、多步骤的重复处理）**由两部分组成：
> - **工作流配置器** [workflow.html](workflow.html)：载入样例文件、编排步骤（21 种操作）、逐步推算表头并校验参数，保存为 JSON 配置，或直接生成放好配置的完整工具包 zip。纯前端，只依赖 SheetJS。
> - **本地执行器** [executor/](executor/)：按 JSON 配置在本机批量处理 Excel（删插列、条件着色、多键匹配回填、比对、区块复制、校验报告），绿色便携包无需安装 Python，包里自带单文件版配置器。
>
> 用户手册见 [executor/docs/使用手册.txt](executor/docs/使用手册.txt)，配置格式见 [executor/docs/配置格式说明.md](executor/docs/配置格式说明.md)。打包：`python executor/build_toolkit.py`（生成 `executor/dist/Excel工作流工具/` 和 zip）；测试：`python -m unittest discover -s executor/tests`（含配置器操作目录与执行器参数的一致性检查）。源码目录里的 `executor/run.bat` 没有自带 Python，双击时会自动转去启动 dist 里打包好的工具。

## 怎么用

- **直接打开**：双击 `index.html`，用 Chrome / Edge 打开即可，不需要安装、不需要服务器。`vendor/`、`js/`、`css/` 三个文件夹必须和它放在一起。
- **部署成网站**：把整个文件夹原样放到任意静态网站托管（Nginx、OSS、GitHub Pages 等）。
- 没有文件时，可点“用示例数据试试”体验（示例数据全部是虚构的）。

## 发给别人用：打包成单个 html

```bash
python build.py
```

会生成 `dist/Excel智能函数助手.html`（约 3MB）和 `dist/Excel工作流配置器.html`（约 1MB），所有代码和组件库都在一个文件里，可以直接用微信、邮件发送，对方用 Chrome / Edge 双击即可使用（AI 功能同样可用）。每次修改代码后重新运行一次即可。打包时还会把 `executor/templates/*.json` 同步到 `js/wf-examples.js`（配置器的“从示例开始”）。

提醒对方：电脑版微信里点开 html 可能会用微信内置浏览器，最好先“另存为”再用浏览器打开；360 等浏览器需切到“极速模式”。

## 已实现

| PRD 要求 | 实现情况 |
|---|---|
| 纯前端、文件不上传 | 读取、计算、生成文件都在浏览器内完成 |
| SheetJS 解析 .xlsx/.xls/.csv | 支持；CSV 自动识别 UTF-8 / GBK，保留“001”这类前导零 |
| ExcelJS 写回 .xlsx | 在原文件基础上新增列 / 新表，原内容和格式不动；.xls、.csv 会转换为 .xlsx |
| HyperFormula 浏览器内计算 | 用于预览和“结果值”模式；补充实现了引擎缺失的 RANK、AVERAGEIFS、AGGREGATE |
| 模板优先 + LLM 兜底（BYOK） | 内置模板先尝试；识别不了且用户填了 Key 时调用 DeepSeek 或通义千问；Key 只存 sessionStorage |
| Excel 2016 函数白名单 | 所有公式（模板与 AI）都要过白名单，IFS / XLOOKUP / TEXTJOIN 等会被拒绝 |
| 结果值 / 公式 双模式 | 默认结果值；公式模式会同时带上计算结果，打开即显示 |

额外做了：自动识别表头行（可手动改）、自动排除末尾“合计”行、提示“文本形式的数字”、出错值的通俗解释、可连续添加多个计算（后面的需求可以引用前面新增的列）、可单独移除某个计算。

## 内置模板能理解的需求（无需 AI）

- **统计**：求和 / 计数 / 平均 / 最大 / 最小 / 中位数 / 不重复个数，可带条件（等于、不等于、大于小于、区间、包含、开头结尾、为空、日期范围、某月份、“或”）
- **分组汇总**：按某列、按两列、按月、按年；可同时算多个指标和占比
- **逐行计算**：四则运算、多列求和/平均（如总分）、条件判断与分档（嵌套 IF）、排名（含组内排名）、累计、占比、所在组的统计值
- **查找**：跨工作表 VLOOKUP / INDEX+MATCH，自动处理“数字 vs 文本”编号不一致；按值查单个结果；“最高的是谁”
- **日期**：年龄、工龄、年/月/日/星期/季度、相差天数/月数、工作日、加减天数/月份、月末
- **文本**：拼接、截取前/后/中间几位、按分隔符取前后段、替换、去空格、长度、大小写、补零、转数字、手机号脱敏
- **身份证号**：出生日期、性别、年龄、脱敏

回归测试：浏览器打开 `tests.html`，会用示例数据跑 46 条典型需求，应全部显示“通过”。

## AI 说明（DeepSeek / 通义千问）

- 在页面右上角“AI 设置”选择服务商、填入 API Key：
  - **DeepSeek**（默认）：在 DeepSeek 开放平台（platform.deepseek.com）创建 Key。模型可选 `deepseek-flash`（默认，快、便宜，关闭思考）或 `deepseek-v4-pro`（更强，开启思考，较慢）。
  - **通义千问**：在阿里云百炼控制台创建 API Key。模型可选 `qwen-plus`（默认）、`qwen-max`、`qwen3.8-max`。默认走 `dashscope.aliyuncs.com` 通用地址；如果账号要求使用工作空间专属地址，在“高级”里填工作空间 ID。
  - 模型名会随厂商更新而变化，可在设置里选“自定义模型名”直接填写最新名称。
- 两家接口都允许浏览器直接调用（已实测），所以不需要后端。智谱、豆包的接口会被浏览器拦截，接入它们需要加服务器转发。
- 发送给 AI 的内容：列名、类型、行数、需求原文，以及（可关闭的）少量示例值。**身份证号、手机号、人名列永远不发送样例。**
- AI 返回的公式同样要通过白名单校验和引擎试算；不通过会把错误反馈给 AI 自动修正一次。返回内容不是合法 JSON、返回空内容、模型不支持 JSON 模式时，也都会自动重试。
- Key 由使用者自己提供（BYOK），按用量计费；每次生成通常只有几千 token。

## 处理上限与 AI 用量控制

所有数字集中在 `js/limits.js`，改完运行 `python build.py` 重新打包即可。

| 项 | 默认值 | 超出时 |
|---|---|---|
| 单个文件大小 | 30MB | 拒绝载入并提示 |
| 每个工作表行数 | 10 万行 | 该表不载入（不截断，避免算错），其他表照常 |
| 每个工作表列数 | 200 列 | 该表不载入 |
| 一个文件的工作表数 | 20 个 | 多出的不载入 |
| 所有表单元格总数 | 300 万 | 多出的表不载入 |
| 单次发给 AI 的内容 | 约 6000 tokens | 自动精简（去掉样例→只保留需求提到的表→…），仍超出则提示删列 |
| 一次“生成”最多调用 AI | 3 次（含自动修正） | 停止并报错 |
| 单次输出上限 | 2048 tokens（思考型模型 8192） | 提示输出被截断 |
| 每天调用次数 | 50 次（使用者可在“AI 设置”里改，0 为不限） | 当天不再调用 AI，模板不受影响 |

费用只和“发给 AI 的表结构描述 + 需求”有关，与文件行数无关：AI 只看到列名、类型和少量示例值，不会收到整份数据。按示例数据估算，一次生成约发送 2000～3000 tokens。

> 这些限制在浏览器里执行，用来防止误用、控制用量；**不是安全措施**。不要把自己的 API Key 写死在 html 里发给别人，任何拿到文件的人都能从源码里取出 Key。

## 已知限制

- PRD 第 3 章“核心用户流程”之后的内容缺失，本版流程按“上传 → 描述 → 预览 → 添加 → 下载”实现。
- 原文件中的图表、透视表在 ExcelJS 写回时可能丢失；.xls / .csv 转换后原有字体颜色等样式会丢失（页面会提示）。
- 预览引擎与 Excel 在极少数边界上可能有差异（如 1900 年 3 月之前的日期、1904 日期系统）；公式模式下以 Excel 自己的计算为准。
- 同一个分组汇总最多 5000 组；表格预览只显示前 100 行（计算和下载包含全部行）。
- HyperFormula 开源版为 GPL-3（PRD 已列为待评估事项）；闭源商用需购买授权或替换引擎。
