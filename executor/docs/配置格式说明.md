# 工作流配置格式说明（excel-workflow/1）

工作流配置是一个 JSON 文件，描述“处理哪些文件”和“按顺序做哪些操作”。网页配置器导出的就是这个格式，高级用户也可以手写。
执行器只按配置执行内置操作，**配置里不能包含程序代码**。

检查配置是否正确：`run.bat --check configs\xxx.json`；列出所有操作及参数：`run.bat --list-ops`。

## 1. 整体结构

```json
{
  "schema": "excel-workflow/1",
  "name": "每周订单整理",
  "description": "给人看的说明",
  "files": [
    {"id": "main", "role": "main", "label": "本周订单", "match": "*本周*.xlsx", "sheet": "明细", "header_row": 1},
    {"id": "last", "role": "ref",  "label": "上周订单", "match": "*上周*.xlsx"}
  ],
  "output":  {"file_name": "{main}_处理结果_{time}.xlsx"},
  "options": {"recalc": "auto"},
  "steps": [ {"op": "delete_columns", "columns": ["内部备注"]} ]
}
```

| 字段 | 说明 |
|---|---|
| files[].id | 文件代号，步骤里用它指代文件（字母、数字、下划线、中文） |
| files[].role | `main` 主表：被处理并输出，**有且只有一个**；`ref` 参照表：只读 |
| files[].label | 运行时提示用的名字 |
| files[].match | 在 input 文件夹里找文件的规则，`*` 代表任意字符；不写则运行时提示拖入 |
| files[].sheet | 默认工作表（名字或从 1 开始的序号），不写=第一个 |
| files[].header_row | 表头在第几行，默认 1；表头下一行到最后一行有数据的行都是数据行 |
| files[].multiple | 只用于参照表：`true` 表示“多个文件”，input 里所有符合规则的文件都会读进来（如各门店的表），只能在 `append_rows` 里使用。主表的规则与它相同时，自动取第一个文件作主表、其余作为追加来源 |
| output.file_name | 结果文件名；可用 `{main}`（主表文件名）`{name}`（工作流名）`{time}` `{date}` |
| options.recalc | `auto`：本机有 Excel/WPS 就重算并检查错误值（默认）；`off`：不重算；`required`：必须重算，没有 Excel/WPS 则失败 |

每个步骤都可以带这些通用字段：`op`（操作名，必填）、`title`（报告里显示的说明）、`file`（作用的文件，默认主表；只有主表能被修改）、`sheet`、`header_row`（覆盖文件的默认值）、`enabled`（false 表示暂时停用）、`note`（备注）。

## 2. 列、区域、条件的写法

**列**（下文写作“列”）：
- `"金额"`：按表头名称找（推荐，列顺序变化也不受影响；忽略多余空格）
- `"L"` 或 `"L列"`：表头里没有这个名字时，按列字母
- `{"letter": "L"}` / `{"index": 12}`：明确按列字母 / 序号

**多列**：`["金额", "数量"]`、`"U:AB"`（列字母区间）、`"开始列名:结束列名"`、`{"from": "金额", "to": "备注"}`

**条件**（`where`）：

```json
{"col": "未分配数", "op": ">=", "value": 10}
{"col": "实发", "op": "=", "col2": "应发"}                  // 两列比较
{"col": "备注", "op": "empty"}
{"col": "状态", "op": "in", "value": ["已发货", "已签收"]}
{"all": [条件1, 条件2]}   {"any": [条件1, 条件2]}   {"not": 条件}
```

op 可用：`= != > >= < <=`、`contains` `not_contains` `starts_with` `ends_with`、`empty` `not_empty`、`in` `not_in`、`regex`、`is_number` `is_text` `is_error`（也可写中文：等于、大于等于、包含、为空……）。加 `"ignore_case": true` 忽略大小写。
数字、日期会按数值比较（"2024-01-05"、"10%" 也能识别）。条件里用到公式列时：简单的四则运算公式按当前数据实时算出，其他公式取文件里保存的计算结果（见“执行规则”）。

在“按匹配复制”中，条件还可以用 `{"ref_col": "入库时间", "op": "not_empty"}` 判断匹配到的参照表那一行。

**写入内容**（`fill`、`insert_column` 共用，四选一）：

| 写法 | 含义 |
|---|---|
| `"value": 0` | 固定值（数字、文本、true/false、null 表示清空） |
| `"formula": "=[@单价]*[@数量]"` | 公式模板：`[@列名]` 同一行单元格，`[列名]` 整列数据区域（$L$2:$L$100），`{row}` 当前行号 |
| `"formula_from": {"file": "last", "sheet": "明细", "cell": "P2"}` | 复制某个单元格的公式，像 Excel 粘贴一样平移相对引用 |
| `"from_col": "旧金额"` | 取同一行另一列的值 |

## 3. 操作一览

### 列
| op | 说明 | 参数 |
|---|---|---|
| delete_columns | 删除列 | columns |
| insert_column | 插入列 | header；位置四选一：before / after / at（列字母）/ end:true；可选写入内容、where、style_from（left 默认/right/none/某列）、width |
| rename_header | 改表头 | column, to |
| set_cells | 写指定单元格 | cells：`{"AC1": "备注", "B2": "=SUM(B3:B9)"}` |
| number_format | 数字格式 | columns, format（如 `#,##0.00`、`yyyy-mm-dd`、`0%`），可选 where |
| set_width | 列宽 | columns, width |

插入、删除行列时，执行器会像 Excel 一样同步调整：所有工作表中的公式引用、合并单元格、列宽行高、条件格式、数据验证、筛选范围、冻结窗格、名称。被删掉的单元格引用变为 `#REF!` 并在报告中提示。

### 行
| op | 说明 | 参数 |
|---|---|---|
| delete_rows | 删除行 | where / rows（"5:10"）/ blank:true（删整行为空的行）三选一 |
| keep_rows | 只保留符合条件的行 | where |
| insert_rows | 插入空行 | before_row 或 at_end:true；count |
| dedupe_rows | 删除重复行 | keys（不写=所有列），keep: first / last |
| sort_rows | 排序 | by: `[{"column": "金额", "order": "desc"}, {"column": "日期"}]` |

### 填充与格式
| op | 说明 | 参数 |
|---|---|---|
| fill（别名 write_if） | 在某列写入内容 | column + 写入内容；可选 where、rows、only_empty |
| fill_down | 向下填充（像 Excel 下拉） | columns；from_row（默认第一行数据）、to_row、with_style |
| replace_text | 查找替换 | columns, find, replace；match_case、whole_cell、regex、where |
| format（别名 color） | 按条件设置格式 | columns；where、fill（颜色如 FCE4D6）、font_color、bold、clear_fill、number_format、include_header |

### 跨表匹配
| op | 说明 | 参数 |
|---|---|---|
| match | 建立匹配 | id（后续步骤引用）、ref（参照表文件 id）、main_keys（单列或多列组合）、ref_keys（不写=同名）；ref_sheet、ref_header_row、ignore_case、trim、duplicates（first/last/error）、ref_where |
| copy_matched | 按匹配复制 | match；columns：`["入库时间", {"from": "金额", "to": "上周金额"}]`；mode：value（默认）/ formula；where（可用 ref_col）；skip_empty（默认 true，参照表为空时不写）；only_empty；fill + color_columns（给匹配行着色）；not_found：`{"column": "备注", "value": "未找到"}`；copy_format；create_missing（主表没有目标列时自动加在最后） |
| compare | 比对差异 | match；compare_columns（默认同名列，或 `[{"main": "金额", "ref": "上周金额"}]`）；tolerance（数值容差）；status_column、diff_column、labels；highlight（差异单元格底色）；report_sheet（在结果里新建比对报告表，null 不建）；export_csv |

键的比较规则：去掉首尾空格；数字 1 与文本 "1" 视为相同，但 "001" 与 1 不同；日期按日期比较。

### 多文件合并与分组汇总
| op | 说明 | 参数 |
|---|---|---|
| append_rows | 把参照表（或“多个文件”）的数据行接到主表末尾，**按表头名称对应列**（列顺序不同也可以） | from：`{"file": "stores", "sheet": "销售", "header_row": 1}`；source_column（写来源文件名的列，新建时主表原有行也会标上主表文件名）；add_missing_columns（来源有、主表没有的列加在最后，默认否）；extend_formulas（来源里没有的列，按主表最后一行的公式补上，默认是；来源里有值的列照抄来源的值）；skip_blank（跳过空行，默认是）；where（按来源文件的列筛选，如去掉合计行：`{"col": "商品编码", "op": "not_empty"}`） |
| group_summary | 按一列或多列分组，生成新的汇总工作表 | group_by；metrics：`[{"column": "金额", "func": "sum", "title": "销售额"}, {"func": "count"}]`，func 可用 sum / count / avg / max / min / count_distinct；sheet_name（默认“分组汇总”）；mode：formula（默认，写 SUMIFS 等 Excel 2016 公式，数据变了打开即更新）/ value（写结果值，才能用 count_distinct 和 where）；sort：key（按分组列升序，默认）/ metric_desc（按第一个指标从大到小）；total_row（默认加合计行）；replace |

追加行之后，以主表最后一行数据结尾的区域（其他表的汇总公式、筛选、条件格式、数据验证）会自动延伸到新行。主表最后一行若是“合计”行，新数据会排在它下面，报告会提醒先删掉合计行。

### 复制区块 / 工作表
| op | 说明 | 参数 |
|---|---|---|
| copy_range | 区块复制 | from：`{"file": "last", "sheet": "汇总", "range": "AF1:AI30"}`；to：`{"cell": "AF1"}`；content：values/formulas/styles/widths/merges 的组合（默认全部）；formula_fallback：value（默认）/ error |
| copy_sheet | 把参照表的整张工作表复制进主表 | from：`{"file": "last", "sheet": "单价表"}`；name；replace |

**跨文件公式**：执行器不支持跨文件引用。复制公式时，引用的工作表在主表里存在就保留公式（相对引用自动平移），否则改为复制计算结果（`formula_fallback: "error"` 则直接报错）。需要保留公式时，先用 copy_sheet 把被引用的表复制进主表。

### 校验
`{"op": "validate", "checks": [...]}`，每项可加 `"on_fail": "stop"`（不通过就中止、不输出文件）和 `"message"`：

| type | 参数 |
|---|---|
| required_columns | columns |
| not_empty | columns |
| unique | columns（多列=组合不重复） |
| row_count | min, max |
| headers_match | file（另一个文件 id）、columns（如 "A:AB"），比较同位置表头是否一致 |
| condition | where, expect：none（不应有符合的行）/ all / any |

## 4. 执行规则
- 输入文件只读，结果先写临时文件，全部成功才生成结果；任一步失败不输出结果，只输出报告。
- 执行器不负责计算公式，但条件、排序、去重、匹配、分组需要读公式的值：“同一行单元格之间的四则运算”这类简单公式（如 `=G5*H5`、`=ROUND(K5*1.13,2)`，可用 ROUND / ABS / MAX / MIN / INT）按当前数据实时算出；其他公式用文件里保存的计算结果，本次新写入的复杂公式还没有结果，按空值处理（配置器会提前提醒）。
- `recalc: auto` 时会用本机 Excel/WPS 重算并扫描错误值，否则只做语法检查（括号配对、#REF!、是否用了 Excel 2016 没有的函数）。
- 不支持：.xls（请先另存为 .xlsx）、保留图表和图片、在“Excel 表格（Table）”内部插入/删除行列（请先转换为区域）。

## 5. 自定义操作（开发者）
在工具包的 `extensions` 文件夹放一个 .py 文件即可增加操作：

```python
from engine.ops import op, font_with


@op("mark_negative", "负数标红", required=["column"])
def mark_negative(ctx, step):
    view = ctx.view(step)                 # 目标工作表
    c = view.col(step["column"])          # 按表头定位列
    n = 0
    for r in view.data_rows():
        v = view.get(r, c)                # 当前值（公式取已保存的计算结果）
        if isinstance(v, (int, float)) and v < 0:
            cell = view.ws.cell(row=r, column=c)
            cell.font = font_with(cell, color="FF0000")
            n += 1
    return {"rows": n, "detail": f"{n} 个负数标红"}
```

配置里就可以使用：`{"op": "mark_negative", "column": "利润"}`。

需要改动行列结构时，请调用 `engine.book.restructure(...)`，它会同步调整公式和格式。
