Excel 工作流工具 · 使用手册
==============================

这个工具按“工作流配置”自动处理 Excel 文件：删列、插列、按条件标色、两表匹配回填、比对差异、复制公式和格式……
全部在你自己的电脑上运行，不联网，不需要安装 Python，也不需要管理员权限。原文件永远不会被修改。

一、整体流程
  ① 配置（做一次）：用「工作流配置器.html」把要做的处理步骤配置好，保存成 .json 配置文件。
  ② 执行（每次）：把新表格放进 input，双击 run.bat，到 output 拿结果和校验报告。

二、第一次使用
  1. 把压缩包完整解压到任意文件夹（不要在压缩包里直接双击运行）。
  2. 配置工作流：双击「工作流配置器.html」（用 Chrome 或 Edge 打开）。
       · 左边“文件”：拖入一份样例表格（第一个是主表，也就是要处理并输出的表；比对、匹配用的其他表是参照表）。
         样例只用来读取表头、方便选择列名和检查配置，只在本机读取，不会上传。
       · 中间“处理步骤”：点“添加步骤”，选择操作并填写参数；步骤从上到下依次执行，可以拖动调整顺序。
         参数有问题会标红，并说明原因（例如前面的步骤已经删掉了这一列）。
       · 下方“保存与导出”：起个名字，点“保存配置文件（.json）”，保存到本工具包的 configs 文件夹。
         也可以点“生成完整工具包（.zip）”：得到一个已经放好配置的工具包，直接发给同事解压就能用。
     别人发给你的 .json 配置，直接放进 configs 文件夹即可；想修改时在配置器里“打开配置…”。
  3. 把要处理的 Excel 文件（.xlsx）放进 input 文件夹。
  4. 双击 run.bat。
  5. 处理完成后，结果在 output 文件夹：
       xxx_处理结果_时间.xlsx   处理后的文件
       xxx_校验报告.txt         每一步做了什么、处理了多少行、有没有问题
       xxx_执行日志.log         出问题时给技术人员看的详细记录

  想先体验：configs 里还没有配置时直接双击 run.bat，窗口里会列出内置示例，输入序号即可用自带的示例数据运行。
  配置器右上角“从示例开始”也能打开这些示例，在它们的基础上修改。

三、运行时会发生什么
  · configs 里有多个工作流时，会让你输入序号选择。
  · 工具会按配置里的规则在 input 文件夹里找文件（例如文件名包含“本期”）。
    找到多个会让你选；找不到会提示你把文件直接拖进黑色窗口再按回车。
  · 也可以把 Excel 文件直接拖到 run.bat 图标上启动。
  · 本机装有 Excel 或 WPS 时，工具会在后台打开结果文件重算一遍公式，再检查有没有 #REF!、#VALUE! 等错误（可能需要几十秒，期间不要操作弹出的 Excel/WPS 窗口）。

四、看懂校验报告
  ✔ 表示这一步成功，下面一行是处理了多少行、写了多少个单元格。
  ⚠ 表示需要留意，但不影响生成结果（例如参照表里有重复的键）。
  ✘ 表示失败：任何一步失败，工具都不会生成结果文件，原文件也没有被改动。按报告里的“失败原因”修改后重新运行即可。
  “公式检查”里的 #N/A 通常是查找不到对应值，不一定是错误；其他错误值请打开文件核对。

五、常见问题
  问：双击 run.bat 一闪而过或被杀毒软件拦截？
  答：在杀毒软件里把整个工具文件夹加入信任后再双击。工具不需要管理员权限。
  问：提示“找不到列”？
  答：说明文件表头和配置里写的列名不一致（多了空格、改了名字、表头不在第 1 行）。按报告里列出的“现有表头”核对。
  问：提示文件不是 .xlsx？
  答：旧版 .xls 文件请先在 Excel/WPS 里“另存为”.xlsx 再处理。
  问：打开结果文件发现图表、图片没了？
  答：执行器不支持保留图表和图片，报告里会提示。需要的话请在结果文件里重新插入。
  问：公式显示的是旧数值？
  答：公式的最终结果在 Excel/WPS 打开文件时计算；打开后按 Ctrl+Alt+F9 可强制全部重算。
  问：能处理多大的文件？
  答：1 万行约几秒到二十秒（含重算），10 万行约一分钟左右；电脑内存建议 8GB 以上。

六、注意
  · 只运行来自可信来源的工具包和配置文件；extensions 文件夹里的 .py 是程序代码，不要放来历不明的文件。
  · 工具包支持 Windows 10 / 11（64 位）。
